# ChangeLogMonitor.Api

REST API для работы с журналом изменений.

## Структура

- **Controllers/** - API контроллеры для работы с данными журнала

## Назначение

Предоставляет REST API для:
- Получения списка изменений
- Фильтрации и поиска
- Получения деталей конкретного изменения
- Экспорта данных в различных форматах
