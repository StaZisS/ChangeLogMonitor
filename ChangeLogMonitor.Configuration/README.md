# ChangeLogMonitor.Configuration

Модуль для работы с YAML конфигурацией аудита.

## Структура

- **Providers/** - Провайдеры для загрузки и валидации конфигурации
- **Models/** - Модели конфигурации

## Назначение

Обрабатывает YAML конфигурацию, которая определяет:
- Какие таблицы/сущности логировать
- Какие поля маскировать (для чувствительных данных)
- Правила фильтрации
- Настройки хранения данных
