# ChangeLogMonitor.Core

Основной модуль проекта, содержащий базовые интерфейсы, модели данных и абстракции.

## Структура

- **Models/** - Модели данных для журнала изменений
- **Interfaces/** - Интерфейсы для основных компонентов системы
- **Enums/** - Перечисления (типы операций, статусы и т.д.)

## Назначение

Этот модуль является фундаментом для всех остальных модулей и не содержит зависимостей от других частей проекта.
