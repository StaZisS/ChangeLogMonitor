# ChangeLogMonitor.DataAggregator

Модуль для агрегации данных из Kafka (Debezium) и соединения основных данных с метаданными.

## Структура

- **Consumers/** - Kafka consumers для получения CDC событий из Debezium
- **Services/** - Сервисы для обработки и агрегации данных
- **Models/** - Модели для работы с Debezium событиями

## Назначение

Получает события Change Data Capture (CDC) от Debezium через Kafka и:
- Соединяет данные из основной таблицы с таблицей метаданных
- Обогащает события дополнительной информацией
- Подготавливает данные для отображения в UI
