# ChangeLogMonitor.Embedded

Библиотека для встраивания функциональности аудита в основное приложение.

## Структура

- **Extensions/** - Extension методы для регистрации сервисов в DI контейнере

## Назначение

Предоставляет возможность встроить систему аудита в существующее приложение:

- Регистрация интерцептора в EF Core
- Регистрация конфигурации
- Настройка всех необходимых сервисов

Используется когда нужно встроить аудит прямо в основное приложение.
