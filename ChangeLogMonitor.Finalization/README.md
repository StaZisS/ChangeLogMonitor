# ChangeLogMonitor.Finalization

ClickHouse sink и REST API для дифов.

**Возможности:**
- Консьюмер Kafka
- Хранение в ClickHouse
- REST API для выборки дифов

**Запуск:**
```bash
dotnet run --project ChangeLogMonitor.Finalization
```
