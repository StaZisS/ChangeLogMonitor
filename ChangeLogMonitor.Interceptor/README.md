# ChangeLogMonitor.Interceptor

Модуль для перехвата изменений в Entity Framework Core и записи их в таблицы аудита.

## Структура

- **Interceptors/** - EF Core интерцепторы для перехвата операций SaveChanges
- **Services/** - Сервисы для обработки и сохранения изменений

## Назначение

Перехватывает изменения во время транзакции и записывает их в:
- Таблицы с изменениями данных
- Таблицу с метаданными

Работает в рамках транзакции основного приложения.
