# ChangeLogMonitor.UI

Razor Pages UI для отображения журнала изменений данных.

## Структура

- **Pages/** - Razor Pages для отображения журнала
- **Components/** - Razor компоненты для переиспользуемых элементов UI

## Назначение

Предоставляет пользовательский интерфейс для:
- Просмотра журнала изменений
- Фильтрации и поиска по изменениям
- Просмотра деталей изменений (до/после)
- Экспорта данных
